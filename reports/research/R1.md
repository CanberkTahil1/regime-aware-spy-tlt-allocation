## D1.1 — Cash / bill series
- (a) [rec] H.15 3-month secondary-market discount (`RIFSGFSM03_N.B`), converted to an investment return
  r_s = P^(−Δ/91) − 1, P = 1 − d·91/360, d = last rate dated ≤ previous session (Δ calendar days). Covers 1954→; same
  series and rule as the sibling (one convention across repos). H.15 footnote: "On a discount basis" (LICENSES.md).
- (b) 4-week bill: starts 2001-07, cannot cover warm-up/development 1986–2000. (c) KF RF: excluded (Ibbotson/ICE; charter).
- Financing base = the same bill rate (annualised discount ≈ money-market yield; spread 25 bp per charter); dt = Δ/360.

## D1.2 — TLT proxy construction details
- (a) [rec] `quantkit.bonds.total_return(gsw, 25, roll="daily", m=2, max_gap_days=7)` = the construction the sibling

## D1.3 — `rspy.accounting` design (one function for every rung)
- (a) [rec] Input: target weights decided at close t (rows = decision sessions; daily rungs every session, monthly at
  month-end). Execution at close t+1 (lag 1 session); held from t+1's close, earning from t+2. Between trades holdings
  drift with returns. Turnover_t+1 = Σ|w_target − w_drifted| (true traded turnover, vol-scaling and drift included).
  Costs = `quantkit.costs.Proportional([3e-4, 2e-4])` per side (2×/3× stress rows). Cash = max(1 − Σw, 0) earns the bill;
  borrowed notional pays `costs.financing.accrual(rate = bill, spread 25 bp [+75 bp stress], dt = Δ/360)`. Negative
  target → ValueError (no shorts; a rung must not produce one). Sharpe = `stats.sharpe(net, rf = bill)`; Sortino =
  √252·mean(e)/√mean(min(e,0)²), e = net − bill (standard downside deviation vs 0). Reference loop + equivalence ≤ 1e-10.
- (b) no drift (turnover = Σ|Δw|): simpler, understates turnover for monthly rungs. (c) same-close execution: barred.

## D1.4 — Legacy reconciliation ladder (steps, order, windows)
- (a) [rec] cumulative, one correction per row, on v1's selected params and windows (train 2005–14, validation 2015–19,
  test 2020–2025-12-31): S0 v1 as committed (reproduced) → S1 t+1 execution → S2 cash at bills + financing (bill + 25 bp)
  → S3 costs at charter rates on true traded turnover (with drift) → S4 excess-return Sharpe + standard Sortino (a
  metric change; returns unchanged) → S5 no shorts (negative v1 weights floored at 0 → cash) → S6 permitted prices (SPY →
  KF Hi 20, TLT → GSW 25y proxy, KF calendar; VIX still local) → S7 VIX → realised-vol proxy (= L1). S1–S5 run on v1's
  own cached Yahoo data (as BUILD_PROMPTS prescribes), local only; only derived statistics are committed.
- (b) S6+S7 merged into one "new data" row. (c) apply corrections in reverse order (data first): changes what each row
  attributes; BUILD_PROMPTS order is data last.
