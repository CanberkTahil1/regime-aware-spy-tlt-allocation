L6–L8 are **not** walked. They are evaluated through the charter's ablation table: each layer vs its own parent, plus
vs 60/40 (L3) and vs v1 (L1), with 95% intervals, descriptive. Report L6 and L7 in 1994, 2008 (GFC window) and Q4 2018
at matched risk. Headline via `viz.headline` with the short labels SPY, v1, 60/40, InvVol+VT, +CorrReg, +Trend, +Crash,
SPY+bills into the gitignored reports/figures_local/R3/.

## D3.1 — L6 mechanics (correlation regime → TLT to cash)
- (a) [rec] Pearson correlation of the two sleeves' daily simple returns over the 126 (primary) / 63 sessions ending at
  the **month-end decision close** (all required); decided at the same rows as L4's weights, traded next close.
  L6 target = **L5's daily target with the TLT column set to 0** for every row whose latest decision says corr > 0
  (the vol scale is L5's, not recomputed: "TLT's weight moves to cash" literally, the book runs below 10% vol while
  gated). A sleeve whose target is exactly 0 exits fully (the band is not applied to a zero target; R2 books
  bit-identical since none had one). Threshold 0; ±0.2 descriptive rows; L6-63 a descriptive row.
- (b) As (a) but re-run the vol target on the gated book (SPY scaled up to fill the 10%). Not "to cash": it adds SPY
  exposure in the 1994-type months, a second change in one layer.
- (c) Daily gate decisions (correlation at every close). At 0.57–0.97 monthly switches the daily state flips more
  often near 0 (SE ≈ 0.09), more turnover for no source-backed gain; the charter fixes daily decisions only for the
  vol target.
- (d) Keep the band on a zero target (exit to 5 pp). Leaves a 5 pp TLT stub the rule says should be cash.
- Pushback: "why not re-lever SPY when TLT leaves?" — that is (b); it confounds the correlation layer with a leverage
  change. The ablation measures at matched vol anyway, so (a) loses nothing in the comparison.

## D3.2 — L7 mechanics (per-asset trend)
- (a) [rec] `quantkit.signals.trend.faber(R, dates, months=10)` on each sleeve's total-return level (Hi 20, GSW 25y
  TR), long-only; the decision of month-end e is the position faber assigns from e + 2, read back to row e (test: equal
  to the SMA computed at our decision rows). L7 target = L6's target with each sleeve below its SMA set to 0 (exits
  fully, D3.1). No re-scaling (same reason as D3.1(a)). L7 on L6-126 is the rung; trend on L5 alone (no L6) is a
  descriptive "trend without correlation" row so the two layers can be separated.
- (b) Price (not total return) levels: Faber 2007 used total-return series for the asset classes [mem]; we have no
  price-only TLT proxy. (c) Daily `trend.sma(window=210)`: a different, named variant; the charter names faber.
- Pushback: whipsaw (TLT switches 1.9×/yr) — the ablation charges true turnover at 2 bp/side; the 2× / 3× cost rows
  show it.

## D3.3 — L8 crash rule
- (a) [rec] quantkit's drawdown overlay `rule="dd"` with its pre-registered defaults (d1 = 1, d2 = 2.5 in units of the
  10% target: de-risk linearly from a 10% to a 25% drawdown, floor 0.25 exposure; re-risks as the drawdown heals).
  **Test (charter):** `sizing.judge(L7 net − bill, target 0.10, rule="dd", sigma = 0.10 constant, cap 1.0)`: the
  constant σ makes the base exposure exactly 1, so "vol targeting alone" **is L7** (already vol-targeted) and the
  placebo is L7 × the block-shuffled multiplier path (block 21, seed 0). **Book:** L8 target = L7 target × g_t, g_t =
  judge's candidate multiplier stamped t (overlay NAV on L7's excess returns, frictionless), traded at t+1 with costs.
  Disclose: judge's overlay is same-close; the book adds the charter's one-session lag.
- (b) `rule="cppi"` (α 0.8): ratcheting floor, cash lock after a 20% drawdown, never re-risks; unsuitable for a
  core allocation. (c) A vol-spike trigger (EWMA 10/60 log ratio): `judge` only compares drawdown overlays; would need
  a hand-built test.
- Pushback: L5's development max DD (R2, already seen) is modest, so the rule may rarely fire — expected; the BUILD
  prompt already predicts L8 fails `judge`.

## D3.4 — Gate placebo (L6, L7, zoo gates)
- (a) [rec] Shuffle the gate's **monthly decision vector** (one value per month-end) with `quantkit.vol.shuffle_blocks`
  in blocks of **12 months**, seed 0; rebuild the book with the shuffled gate (same parent, same accounting). Status
  "beats placebo" mirrors `alloc.gate` / `judge`: gate vs parent one-sided LW p < 0.05 AND placebo vs parent p ≥ 0.05.
  Descriptive: the gate's matched ΔSharpe percentile among 100 seeds (0–99). Block 12 ≥ the longest median spell
  (8 months), 30 blocks over 30 years.
- (b) quantkit's daily default (block 21 sessions) on the daily carried state, read at month-ends: blocks ≈ one month,
  so the monthly placebo state is nearly a month-level permutation (persistence destroyed, extra turnover makes the
  placebo easy to beat). (c) Block 6 months (≈ median spell): more blocks, shorter runs than the real regime.
- Pushback: one seed is noisy — hence the 100-seed percentile beside the registered single-seed status.
